# Evidence Handling

## Principles

- Preserve original source links.
- Record timestamps in UTC.
- Keep raw notes separate from public reports.
- Redact sensitive personal or wallet backup data.
- Mark every inference clearly.

## Evidence Log Fields

- id
- timestamp_utc
- chain
- tx_hash
- address
- source_url
- observation
- confidence
- reviewer

## Review Checklist

- Can another analyst follow the evidence trail?
- Are claims tied to public sources?
- Is victim-sensitive information removed?
- Are limitations clearly stated?
