# Exchange Escalation Package

Use this structure when preparing a lawful, evidence-based escalation package for a centralized platform or service provider.

## Include

- Incident summary
- Affected wallet addresses
- Transaction hashes and explorer links
- Asset type and estimated value at incident time
- Timeline in UTC
- Screenshots with sensitive data redacted
- Contact information for follow-up

## Avoid

- Seed phrases or private keys
- Unverified accusations
- Personal data unrelated to the incident
- Instructions for bypassing security controls

## Confidence Labels

- Confirmed: directly supported by public chain data or official records.
- Likely: supported by multiple signals but not definitive.
- Unknown: relevant but unresolved.
