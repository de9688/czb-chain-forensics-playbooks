# CZB Chain Forensics Playbooks

Operational playbooks for defensive on-chain investigation, evidence organization, and incident escalation.

## Focus

- Transaction tracing workflow design
- Evidence logs and source preservation
- Exchange or platform escalation package structure
- Public reporting boundaries for sensitive incidents
- Clear separation between facts, labels, and hypotheses
